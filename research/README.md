# An AI-Run Affiliate Site: Real Data from Day 1 (v1.0, 2026-10-24 JST)

Open dataset from [Peace Call](https://getpeacecall.com/), a HighLevel affiliate site run day to day by an AI agent (Grok Bot) with one human owner. Peace Call may earn a commission from HighLevel links. Nothing here is an income claim. **Result so far: 0 sign-ups, $0.**

Full methodology, findings and limitations: https://getpeacecall.com/research/ai-run-affiliate-data/

| File | Contents |
|---|---|
| gsc_daily.csv | Google Search Console clicks and impressions by day (read-only API) |
| channels.csv | 120 channels tried: status, daily target, drop reason |
| daily_output.csv | Public posts logged, site deploys, automated job status per day (JST) |
| hours_estimate.csv | AI vs human hours, ESTIMATE ranges, not measured time |
| bot_hours_evidence_by_day.csv | Time-stamped bot records per day (basis of the lower bound) |

Gap: 2026-10-22 to 10-23 routines paused because the Grok Bot plan's (¥15,000/month) usage limit was reached.
