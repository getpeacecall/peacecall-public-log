# Peace Call public log

Real records from [Peace Call](https://getpeacecall.com/), a HighLevel affiliate site run day to day by an AI agent (Grok Bot) with one human owner. Peace Call may earn a commission from HighLevel links. Nothing here is an income claim.

This repo holds **only scanned, allowlisted public data**. It never contains site source code, logins, keys, email contents, private messages or raw working files. Every file is regenerated by a script and checked by a security scan before it is committed. Each commit is a dated, public, tamper-evident snapshot (Git history can be compared with earlier clones and with the Internet Archive).

| File | What it is | How to verify |
|---|---|---|
| `runs.csv` | Automated jobs per day (Japan time): ran / partial / failed / no record, plus human involvement from the build log | Compare with `posts.csv` and the posts themselves; gaps (for example 2026-10-23) are kept, not filled in |
| `posts.csv` | Public posts on Peace Call's own accounts, with the platform's own post ID and time where its API gives one | Open the URL. For Bluesky, the at-uri resolves on any Bluesky client; for YouTube, the ID and publish time show on the video page. Rows marked `our log only` have no platform time |
| `deploys.csv` | Every Cloudflare Worker version (one per site deploy), from the Cloudflare API, with the build log entries and repo commits of the same day | Compare dates with archived copies of getpeacecall.com and with `build_log.csv` |
| `gsc_daily.csv` | Google Search Console clicks and impressions by day, pulled with the read-only Search Analytics API | Not independently checkable without account access (which we do not share); published as-is, including zeros |
| `build_log.csv` | Dated build log entries (who acted, outcome) | Same as https://getpeacecall.com/build-log/ |
| `archive_snapshots.csv` | Internet Archive copies of our record pages | Open the snapshot URL; the Archive sets the date, not us |

Gaps: on 2026-10-22 and 2026-10-23, Routines paused because the monthly usage limit of our Grok Bot plan (¥15,000/month) was reached. Rows for those days say so instead of a bare `no record`.

Times: `_utc` columns are UTC; `_jst` and `date_jst` are Japan time (UTC+9).
